# Parfüm Lab

Hammadde stoğu, çözeltiler, formül versiyonları, üretimler ve denenen parfümler için telefon uygulaması (PWA).

- `index.html` uygulamanın kendisi
- `config.js` Supabase adresi ve herkese açık (publishable) anahtar
- `schema.sql` veritabanı kurulumu: Supabase › SQL Editor › yapıştır › Run
- `.github/workflows/uyanik-tut.yml` ücretsiz Supabase projesinin uykuya geçmemesi için üç günde bir yoklama

Veriler bu depoda değil, Supabase'de durur. Depodaki anahtar yalnızca giriş yapmış kullanıcının verilere erişebildiği herkese açık anahtardır.
